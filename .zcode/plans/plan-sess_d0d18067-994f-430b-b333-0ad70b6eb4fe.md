### Frontmatter 新规范（新写的笔记使用）

```yaml
---

topic: javascript                # 一级主题：js/ts/vue/react/php/python/go/algorithms/ai/tools/...
subtopic: async                  # 二级主题，可选
tags: [js, async, event-loop]
difficulty: 3                    # 1-5
confidence: 2                    # 1-5  我的掌握度
reviewed: 2026-07-26
next-review: 2026-08-02
source:                          # 来源，可选
  - book: 你不知道的JavaScript(上)

updated: 2026-07-26
---
```

### Dataview 查询示例（写到学习地图.md 和 MOC 中）

```dataview
TABLE WITHOUT ID
  file.link AS "笔记",
  confidence AS "掌握度",
  difficulty AS "难度",
  next-review AS "下次复习"
FROM "10-Notes"
WHERE type = "atomic" AND next-review <= date(today)
SORT next-review ASC
LIMIT 20
```
