# 数据字典

> [!warning]
> 这里只记录表结构、字段语义和示例枚举，不记录真实客户、交易、财务或生产数据。

## users

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | bigint | 用户主键 |
| `name` | varchar | 显示名称 |
| `email` | varchar | 登录邮箱 |
| `email_verified_at` | timestamp | 邮箱验证时间 |
| `is_super_admin` | boolean | 受保护超级管理员标识 |

## personal_access_tokens

由 Laravel Sanctum 管理，用于 APP 和小程序 API Token。不得在知识库记录任何真实 Token。
