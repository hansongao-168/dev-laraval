# ADR-0001 多端技术栈

## 背景

产品以海外市场为主，同时需要支持中国 Web、APP 和微信小程序渠道。

## 决策

- 后端：Laravel 13
- 管理后台：Filament 5
- 全球网站：Next.js 16
- APP：Expo SDK 57
- 微信小程序：Taro React 4
- 数据库：MySQL 8
- 缓存、会话与队列：Redis 8

## 理由

- 全球 Web 与移动生态优先
- React/TypeScript 客户端人才和生态充足
- Taro 能保留 React 技术栈并覆盖微信渠道
- Laravel API 提供统一业务规则和认证边界

## 影响

- UI 不强制跨端共享
- API 类型、错误代码和业务枚举应共享
- 中国与海外服务商必须通过后端接口适配
