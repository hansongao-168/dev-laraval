# 两数之和（LeetCode #1）

## 题意

> 在数组中找出两个数，使其和等于 target，返回下标（每种输入只对应唯一答案）。

## 思路

- 一层循环 + 哈希查找补数 → O(n) 时间 / O(n) 空间
- 经典 hash 表运用

## 代码

```ts
function twoSum(nums: number[], target: number): [number, number] | null {
  const seen = new Map<number, number>(); // 值 → 下标
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need)!, i];
    seen.set(nums[i], i);
  }
  return null;
}
```

## 易错

- 错把值当 key、索引当 value，找的是索引而非值
- 重复元素：当前值和补数相同时会拿到同一个位置 → 但题目限定答案唯一，安全
