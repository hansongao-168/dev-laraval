# 中间件（Middleware）

## 一句话

> 中间件是经过路由前 / 后依次串起来的"管道"，用来做鉴权、限流、格式化、监控等横切逻辑。

## 类型

- **前置**：第一个参数为 `$request`
- **后置**：第二个参数 `$next($request)` 之后再写代码
- **终结**：不调用 `$next`，短路返回响应

## 注册位置

- `bootstrap/app.php` （Laravel 11+ 默认入口），在 `withMiddleware()` 内注册别名/全局
- 中间件类：`app/Http/Middleware/*.php`

## 代码

```php
public function handle(Request $request, Closure $next): Response
{
    if (!$request->user()?->canAdmin()) {
        abort(403);
    }
    return $next($request);
}
```

## 易错

- 把业务逻辑写死在中间件 → 应放 Service / Controller
- 顺序：在 `web` 之后才会拿到 session
