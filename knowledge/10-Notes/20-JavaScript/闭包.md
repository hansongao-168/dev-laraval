# 闭包

## 一句话

> 函数与其外层作用域引用的绑定，记在 [[执行上下文]] 的词法环境里，即使外层已经返回也仍然能访问。

## 为什么重要

- 数据封装、模块模式、柯里化的基础
- React Hooks、Vue Watcher、Node 中间件都依赖闭包

## 代码

```js
function makeCounter() {
  let n = 0;
  return () => ++n;
}
const c = makeCounter();
c(); // 1
c(); // 2
```

## 易错

- 在循环里给事件回调用 `var i`，会拿到同一个 `i`（改用 `let` 或 wrap 函数）
- 在副作用里捕获大对象会阻止 GC
