# 事件循环（Event Loop）

## 一句话

> JS 单线程下，引擎执行宏任务 → 清空微任务队列 → 渲染 → 取下一个宏任务。

## 三阶段

1. **执行栈**：当前同步任务
2. **微任务队列**：`Promise.then` / `queueMicrotask` / `MutationObserver`
3. **宏任务队列**：`setTimeout` / `setInterval` / `setImmediate` / `MessageChannel` / I/O

## 顺序口诀

> 同步 → 微任务 → 一个宏任务 → 微任务 → 一个宏任务 → …（期间浏览器可选渲染）

## 代码

```js
console.log('a');
setTimeout(() => console.log('b'), 0);
Promise.resolve().then(() => console.log('c'));
console.log('d');
// a d c b
```

## 易错

- 微任务清空完毕才取下一个宏任务
- Node 11+ 与浏览器顺序一致（之前是 Node 顺序不同）
