# 结构化提示词

## 一句话

> 用 `角色 / 任务 / 输入 / 约束 / 输出格式` 五段式拆解，把模糊任务变成可复现的提示。

## 五段式

1. **角色**（Role）：身份 / 视角（"你是一位资深 Laravel 后端"）
2. **任务**（Task）：一句话目标
3. **输入**（Input）：喂进去的上下文、代码、错误
4. **约束**（Constraints）：不要做什么、用什么版本、不能联网
5. **输出格式**（Output Format）：JSON / Markdown / 代码 diff / 表格

## 模板

```text
你是一位 <role>。

任务：<task>

输入：
<context>

约束：
- 不能 <forbidden>
- 引用版本 <version>

输出格式：
<JSON / Markdown / 表格 / diff>
```

## 易错

- 角色模糊：只写"专家"不如写"前端 +10 年 + 负责日活百万"
- 没指定输出格式 → 模型 prose 化回答、缺信息
- 没指定约束条件 → 模型臆造依赖
