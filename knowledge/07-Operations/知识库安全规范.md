# 知识库安全规范

> 本规范适用本 `knowledge` Vault 全部笔记，以及 [[00-Home/AI上下文]] 所约束的 AI 协作过程。原 ERP 业务版的强约束（不得存 `.env` / 客户资料 / 财务明细）已进化为更通用的"凭据 + 隐私 + 测试数据"三道防线。

## 禁止保存

- 密码、Token、API Key、Cookie、证书和私钥
- `.env` / connection string / SSH 配置
- 真实个人资料：姓名、邮箱、手机、地址、身份证号
- 生产数据库导出文件、生产日志（含真实业务参数）、未脱敏错误截图
- 商业秘密、内部考评、他人未公开材料

## 可以保存

- 虚构的个人示例（明显占位符或标识化名）
- 脱敏后的字段结构与字段语义
- 不含凭据的接口路径与错误代码
- 公开技术选型结论，不含生产账户信息

## 提交前自检

1. 笔记/截图里是否有真实姓名 / 邮箱 / 手机 / 地址 / 订单号？
2. 是否有密码 / 密钥 / Token / 连接字符串？
3. 附件是否含生产页面截图 / 真实客户数据 / 浏览器已保存凭据？
4. 能否改为虚构示例或字段说明？

任何一项答案为「是」时，不得提交。

## AI 协作补充

- 与 AI 协作时**同样适用**以上规则
- 长上下文先用 [[10-Notes/95-AI-ML/结构化提示词|结构化提示词]]
- 调试报错时先脱敏，把参数值替换为 `<masked>` 再粘贴
- 调用凭据请用 `.env` 注入 + `<env>` 引用，禁止明文出现在对话中
