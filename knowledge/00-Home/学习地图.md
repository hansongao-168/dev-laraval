## 维护规则

1. 新内容先进入 `00-Inbox`，确认分类后再移动。
2. 一个概念只保留一个原子笔记，其他位置只放 MOC 链接。
3. Frontmatter `type` 只能使用：`note` / `atomic` / `book` / `article` / `project-retro` / `daily` / `weekly` / `mocs`。
4. 跨主题的概念在 MOC 中用双向链接串联。
5. 重要技术决策 / 选型变化，先看是否需要新开 ADR（模板已归档在 `90-Templates/_archived-erp/ADR.md`，可复用）。
6. AI 对话中不得出现真实凭据、生产数据、客户隐私信息。

## 今日复习（Dataview）

```dataview
TABLE WITHOUT ID
  file.link AS "笔记",
  topic AS "主题",
  confidence AS "掌握",
  difficulty AS "难度",
  next-review AS "下次复习"
FROM "10-Notes"
WHERE type = "atomic" AND next-review <= date(today)
SORT next-review ASC
LIMIT 20
```

## 最近更新的笔记

```dataview
TABLE WITHOUT ID
  file.link AS "笔记",
  topic AS "主题",
  updated AS "更新"
FROM "10-Notes"
SORT updated DESC
LIMIT 10
```

## 所有原子笔记数量与掌握度分布

```dataview
TABLE WITHOUT ID
  topic AS "主题",
  length(rows) AS "篇数",
  average(rows.confidence) AS "平均掌握度"
FROM "10-Notes"
WHERE type = "atomic"
GROUP BY topic
SORT average(rows.confidence) ASC
```
